# Tu Ruta Cádiz en Camper

Proyecto reconstruido desde cero como web app responsive, sin reutilizar ninguna versión anterior.

## Ejecutar

```bash
python3 server.py
```

Abrir `http://127.0.0.1:8080` en un navegador.

## Estructura

- `index.html`: shell de aplicación.
- `assets/css/app.css`: responsive mobile/desktop.
- `assets/js/data.js`: datos del prototipo y fotografías nuevas de Unsplash.
- `assets/js/app.js`: navegación, cálculo de ruta, filtros, favoritos, timeline y acciones.
- `manifest.webmanifest`: configuración PWA básica.

Las fotografías son referencias nuevas, no recortes ni capturas de las pantallas aportadas.
